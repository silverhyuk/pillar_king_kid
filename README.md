# PillarKing Kids

교육용 웹 실험 **PillarKing Kids**는 "같은 면적의 찰흙으로 만든 기둥"과 "같은 둘레의 줄로 둘러싼 기둥"을 비교하면서, 기둥 단면 모양에 따라 좌굴 강도가 어떻게 달라지는지 직관적으로 설명합니다.  
연구자: 최서아

🌐 **라이브 데모**: https://pillar.tester-it.com/

## 주요 기능
- **찰흙 모드 / 줄 모드 전환**: 동일 면적(A₀) 또는 동일 둘레(P₀) 조건으로 단면을 정규화해 다양한 다각형과 원을 비교합니다.
- **모양 선택 칩 UI**: 삼각형부터 원까지 원하는 단면만 골라 상대 강도를 확인할 수 있습니다.
- **실시간 미리보기**: SVG로 각 단면을 배치해 시각적으로 비교합니다.
- **Strength Score 막대 그래프**: 최소 단면 2차 모멘트 I_min을 기준으로 정규화한 상대 강도를 수치로 제공합니다.
- **위에서 눌러보기 애니메이션**: 기둥이 눌릴 때의 느낌을 단순화된 스쿼시 애니메이션으로 표현합니다.
- **계산식 표시**: 현재 모드에서 사용하는 반지름/둘레 스케일링 공식을 즉시 확인할 수 있습니다.

## 사용 방법
1. 브라우저에서 `index.html`을 직접 열어 주세요. 별도의 빌드나 서버가 필요 없습니다.
2. 좌측 컨트롤에서 모드를 선택하고, 비교할 모양 칩을 토글합니다.
3. `기둥 높이 L` 슬라이더(단위: cm)로 좌굴 길이를 바꾸면 결과가 갱신됩니다.
4. `위에서 눌러보기` 버튼을 눌러 단순화된 압축 애니메이션을 재생할 수 있습니다.
5. 설명 카드의 계산식을 참고해 모드별 스케일링 방법을 학습해 보세요.

## 계산 개요
- **찰흙 모드**: 목표 면적 A₀를 유지하도록 반지름(원) 또는 외접원 반지름(정다각형)을 `r = √(A₀/π)` 및 `R = √(2A₀ / (n·sin(2π/n)))`로 스케일링합니다.
- **줄 모드**: 목표 둘레 P₀(기본값 12 cm)를 유지하도록 `r = P₀ / (2π)` 및 `R = P₀ / (2n·sin(π/n))`을 이용해 정규화합니다.
- 단면 2차 모멘트(I) 계산 시 재료, 경계조건 등은 동일하다고 가정하며, 모양에 따라 상대값만 비교합니다.

## 계산식 검증 요약
- **반지름/외접반지름 스케일링**  
  - 찰흙 모드: `r = √(A₀/π)`, 정 n각형 외접반지름 `R = √(2A₀ / (n·sin(2π/n)))`  
  - 줄 모드: `r = P₀/(2π)`, 정 n각형 외접반지름 `R = P₀ / (2n·sin(π/n))`  
  - 위 식은 기하학 정식과 일치하며, n→∞일 때 정다각형 식이 원의 식으로 자연스럽게 수렴합니다.
- **단면 강도 계산 근거**  
  - 원: 중심 주축 기준 `I = πr⁴/4`  
  - 정 n각형: 쇼레이스 공식 + 평행축 정리로 중심 주축 2차 면적모멘트를 정확히 구합니다. 면적 ~ R², I ~ R⁴ 스케일링이 유지됩니다.  
  - 좌굴 비교 공식 `P_cr ∝ I/(KL)²`에서 재료·경계조건이 동일하면 순위는 I 값 순과 동일합니다.
- **Strength Score 지수**  
  - 찰흙 모드 `Score = (I/I_max)^{1.25} × 100`, 줄 모드 `Score = (I/I_max)^{1.10} × 100`  
  - 지수는 단조 증가 함수여서 순위를 바꾸지 않고, 시각적으로 차이를 강조하기 위한 스케일링 역할을 합니다.
- **샘플 체크**  
  - A₀ = 0.01 m², n = 4일 때 `R = √(2A₀/(4·sin(π/2))) ≈ 0.07071 m` → 변 길이 ≈ 0.10 m, 면적 ≈ 0.01 m²로 역산 값과 일치합니다.
